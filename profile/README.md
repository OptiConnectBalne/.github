# OptiConnect

SaaS de gestão para óticas, unificando em uma única plataforma o que hoje
exige múltiplas ferramentas de CRM e ERP — com integração futura a APIs de
Ads (Meta Ads, Google Ads).

## Status

Em desenvolvimento — MVP single-tenant, validando a solução com a
**Óticas Balne** antes de expandir para outras óticas.

## O que estamos construindo

- Gestão de relacionamento com clientes (CRM), com o Kommo como referência
  de estrutura
- Gestão operacional/comercial (ERP)
- Integração com plataformas de anúncios (roadmap)
